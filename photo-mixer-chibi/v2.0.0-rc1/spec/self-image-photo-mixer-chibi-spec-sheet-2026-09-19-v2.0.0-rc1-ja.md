## 目的

同時添付写真を高精細のまま保ち、対象本人を約10cmの生きたアニメちびキャラとして一人だけ統合する。真面目な存在から、やんちゃ、隠れ、わちゃわちゃした介入までを同じ連続範囲で許す。

この仕様書は一つの機能familyを単位とし、PROMPT OUTPUTとIMAGE OUTPUTの共通仕様および端末差分を同じ文書に収録する。コンパイラ本文の代替ではなく、利用・検証・受け入れ判定のための外部仕様である。実行時は各正本コンパイラを権威とする。

## 系統と責務

PHOTO MIXERの写真保存規律に、約10cmの生きたちび化、広い行動域、任意の行動連動要素を加える。

## 必須入力

- 現在の実行依頼と、埋め込み成果物を除外した利用可能な会話文脈。
- 同じ呼び出しに添付された写真がちょうど一枚必要。過去画像や生成画像で代用しない。
- 対象または編集元写真だけが不足・曖昧な場合、一問で不足項目だけを確認する。

## 共通の自己像コア

- 現在の発話行為から描画対象を一人だけ解決する。`you`、`yourself`、あなた、君自身などは、その発話が実際に向けられた会話相手を指す。
- 対象本人がすでに持つ能動的な自己像を一次権威として直接取得する。会話は補完にのみ使い、別人格の生成や平均化には使わない。
- 以前の$imagegenプロンプトや生成用プロンプトは、内容を読まず不透明なpayloadとして切除してから補完を行う。
- 過去画像の感想、誤描画の報告、修正依頼はdepiction reportとして隔離し、本人が明示的に採用しない限り身体特徴へ昇格させない。
- 個人情報は関係性や因果だけを保つ役割表現へ記号化し、実名、住所、勤務先、連絡先、資格情報、私的予定などを最終プロンプトへ出さない。
- 正の情報だけから最小自己像packetとmarked-anatomy allowlistを作り、場面決定前に対象、身体、本人性を凍結する。
- 凍結後は、場面、画像、画風、衣装、レンダラーの既定値による別人格への置換を許さない。

対象がなお複数に解釈できる場合、コンパイラは誰を描くかだけを一問で確認する。利用者に名前、年齢感、性別表現、身体特徴の全項目を再入力させない。短い回答は同じ実行の不足欄だけを埋める。

## 画像権限

- 添付写真は唯一のシーン兼編集ベースであり、縦横比、物体、食べ物、文字、光、素材、遠近を規定する。
- 写真内の人物や顔は、ちび本人の顔・身体・本人性を供給しない。
- 既存の写真要素をなるべく保存し、ちびの接触に必要な局所変化だけを許す。
- 元の可読文字は保持し、新しい文字は後述の任意micro-expressionだけを例外とする。

## シーン・行動・構図

- 自己像と約10cmの身体変換を凍結した後、写真の内容を見る前に一つのatomic facetを固定する。次に写真全体を読み、全行動域から行動または静止状態を選び、任意要素を決めてから局所配置を解く。
- 対象本人を一人の生きた約10cmちびキャラへ変換する。小ささは本人の置換ではなく、この派生版固有の身体スケール表現である。
- 静かに見つめる、真面目に作業する、普通に居る、遊ぶ、いたずらする、物陰から一部だけ覗く、画面端で介入する、わちゃわちゃ動く、の全域を許す。どれも必須にしない。
- 中央配置や全身表示を義務化しない。物の陰から顔だけ見えるなど、空間的に正しい部分遮蔽を許す。
- 必要なら行動に結び付いた小物や少量の物質を追加できる。必要なら本人所有の短い手書き語句一〜二片、ハート等を加えられるが、写真説明文にはせず、行為・反応・意図として機能させる。文字は必須ではない。

## 描画と保持

- 元画像の縦横比、向き、カメラ、写真らしい高精細さを維持する。
- 追加するちびだけを日本アニメ調にし、写真世界を描き直さない。
- 既存文字の可読性を守り、任意micro-expression以外の新規字幕、吹き出し、署名、透かしを加えない。

## Terminal構成

| 項目 | PROMPT OUTPUT | IMAGE OUTPUT |
| --- | --- | --- |
| 返却物 | 完成した英語の `$imagegen` プロンプト一つ | 編集済み画像一枚 |
| プロンプト | 単一コードフェンスで可視 | 内部に保持して非表示 |
| 画像tool | 呼び出さない | 一回だけ呼び出す |
| 推奨環境 | Chat / Work | 画像対応Work |
| 画像の受け渡し | 後段で同じ元写真を再提示・再添付する必要がある場合がある | 同時添付された元写真を、同じ実行内で直接渡す |
| Chatでの反復 | 比較検証に適する | 二回目以降に最初の内容が再利用されたような結果が起こり得る |

## PROMPT OUTPUT端末契約

- 完成した英語の$imagegenプロンプトを一つだけ、単一のコードフェンス内に返す。
- プロンプトの前後に説明、見出し、解説、候補、生成画像を付けない。
- 内部の対象解決、自己像取得、候補、監査、修復過程は開示しない。

## IMAGE OUTPUT端末契約

- 成功時は画像を一枚だけ返して停止する。準備説明、題名、キャプション、事後解説は付けない。
- 技術的再試行は一枚も生成されなかった場合だけ許し、好みの別案を得るためには使わない。
- 完了後は呼び出し固有の凍結プロンプトと実行状態を再利用不可として破棄する。

## 標準処理順

1. 端末modeを固定し、現在の呼び出しと利用可能な会話を受け取る。
2. 外側の会話と埋め込み成果物を分け、過去の生成プロンプトpayloadを残滓なく切除する。
3. 実際の呼びかけ関係から対象を解決する。
4. depiction reportを隔離し、個人情報を記号化してから、本人の確立済み自己像を取得し、会話による補完を限定的に適用する。
5. 最小の正の自己像packet、必須身体、marked anatomyを凍結する。
6. 約10cmへの身体変換 → 一つのatomic facet → 写真全体解析 → 全行動域から状態固定 → 任意要素固定 → 局所保存record → 配置・遮蔽 → 写真保存型render
7. 自己同一性、プライバシー、物理整合、画像権限、出力形式を監査し、最短の失敗段階だけを修復する。
8. 選択したterminalに従い、PROMPT OUTPUTでは完成プロンプト一つだけを返し、IMAGE OUTPUTでは一回の画像呼び出し後に画像一枚だけを返す。

## 使用手順

### PROMPT OUTPUT

1. 編集元となる写真を一枚だけ同じ呼び出しに添付し、コンパイラ本文を実行する。
2. 対象または元写真について一問だけ確認された場合、その項目だけを短く答える。
3. 出力されたコードフェンス内の$imagegenプロンプトを後段へ入力する。
4. 後段の画像編集でも同じ元写真を利用できるようにし、求められたら再提示または再添付する。

### IMAGE OUTPUT

1. Workで編集元となる写真を一枚だけ同じ呼び出しに添付し、コンパイラ本文を実行する。
2. 対象または元写真について一問だけ確認された場合、その項目だけを短く答える。
3. 内部コンパイルと一回の画像呼び出しを待つ。
4. 返された一枚を結果とし、同じ呼び出しから別案を要求しない。

## 制約と既知の挙動

### PROMPT OUTPUT

- 画像を使う派生版では、プロンプトを作った時の画像ピクセルがテキストへ埋め込まれて後段へ自動移送されるとは限らない。
- 後段で同じ画像を求められたら、画像が直前に見えている場合は `Use the image above.`、認識されなければ再添付する。
- 画像を使わない新規生成が編集扱いされた場合だけ `Completely new generation. No reference image.` を使う。PHOTO MIXER系には使わない。

### IMAGE OUTPUT

- 実運用上はWork向け。Chatでは初回が成功しても、二回目以降に最初のプロンプトまたは画像が再利用されたような同一出力が起きることを確認している。
- 原因を内部キャッシュと断定せず、Chatの直接実行状態に関する既知の制約として扱う。Chatで反復検証する場合はPROMPT OUTPUTを使う。
- 曖昧な対象や必須画像について確認が入ることはあり、その回答は同じ一回の呼び出しを継続する。

## 推奨用途

写真内の食べ物、器、机、機械、植生、日用品などと、約10cmの自己像を自由な温度感で遊ばせたいとき。

## 非推奨用途

約10cmへのちび化を必要としない人物合成、完全新規世界、常に文字や常に騒がしい行動を要求したいとき。

## 受け入れ条件

### 共通

- 描画対象が現在の発話から一人に確定し、別の会話人格、コンパイラ実行者、過去画像の人物へ置換されていないこと。
- 以前の生成プロンプト、depiction report、画像内人物から、未承認の身体特徴や人格が混入していないこと。
- 自己像の補完に必要な関係性は残しつつ、保護すべき個人情報が可視化または可読化されていないこと。
- 同時添付写真を保ったまま、約10cmの生きたちび本人一人が自由だが因果的に整合する状態で統合されていること。

### PROMPT OUTPUT

- 画像ツールを呼ばず、完成した一個の$imagegenプロンプトだけをコードフェンスで返すこと。

### IMAGE OUTPUT

- 凍結プロンプトを開示せず一回だけ画像呼び出しを行い、成功後は画像一枚だけを返すこと。
